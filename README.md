# 🃏 Desafio Super Trunfo - Países

Este projeto foi desenvolvido como parte de uma atividade acadêmica da faculdade, com o objetivo de praticar lógica de programação e desenvolvimento em linguagem C.

O desafio original foi fornecido pela empresa fictícia MateCheck como base para o exercício, e a partir dele foram realizadas implementações e adaptações durante o aprendizado.

## 📚 Sobre o Projeto

O projeto consiste na criação de um sistema inspirado no jogo Super Trunfo, com o tema "Países", onde cartas representam cidades e possuem diferentes propriedades para comparação.

O desenvolvimento foi dividido em três níveis de dificuldade:

### 🎮 Nível Novato
- Cadastro de cartas via terminal utilizando `scanf` e `printf`
- Entrada e exibição de dados como:
  - População
  - Área
  - PIB
  - Pontos turísticos

### 🛡️ Nível Aventureiro
- Implementação de propriedades calculadas:
  - Densidade populacional
  - PIB per capita

### 🏆 Nível Mestre
- Comparação entre cartas
- Implementação de regras para determinar a carta vencedora
- Cálculo de "Super Poder" com base nas propriedades

## 💻 Minhas contribuições
- Implementação das funcionalidades de entrada e saída de dados
- Desenvolvimento dos cálculos (densidade populacional e PIB per capita)
- Lógica de comparação entre cartas
- Organização e estruturação do código

## 🚀 Tecnologias utilizadas
- Linguagem C
